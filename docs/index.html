資料箱 ・ 元加賀小学校

2026年10月15日に届いた12点（サンプル取り込み）

作文を灯りにした見本（架空サンプル）

昭和35年度の文集の中身を想定して、見本として作った架空の作文4編です。実在の児童や内容ではありません。本物の作文を撮影したら、この4編と置き換えます。
取り込んで見えてきたこと（推定を含みます）

卒業の回数と年度が、第45回＝昭和29年度、第52回＝36年度、第56回＝40年度、第58回＝42年度（4年だより）、第66回＝50年度と、毎年1回ずつきれいにそろいます。逆算すると第1回の卒業は1911年3月ごろ。開校年は記念誌『もとかが』で確かめたいところです。

昭和35年度の文集、昭和42年度とみられる文集、そして記念誌。3冊の表紙に、筏師や掘割の橋が子どもの手で彫られています。1974年に木場の堀が埋め立てられていく前の、子どもたちの目に映った水辺の町です。

空襲の証言に出てくる「逃げ込もうとした元加賀小学校」は、この学校です。戦後10年目の文集『むらくさ』の表紙には、鉄筋の校舎が写っています。
